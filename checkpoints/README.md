# Checkpoints

Download the VPGNet checkpoint from Hugging Face:

```bash
bash scripts/download_checkpoint.sh
```

This creates `checkpoints/vpgnet_sam3fp1_best_epoch24.pth`.

Expected SHA256:

```text
0be40e94ab990aad9f1cd22b322fbc6957db7e52a8c9efb296e5044f5b52e1c5
```

Download the dataset before evaluation:

```bash
bash scripts/download_dataset.sh
```
