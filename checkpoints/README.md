# Checkpoints

Download the VPGNet checkpoint from Hugging Face:

```bash
bash scripts/download_checkpoint.sh
```

This creates `checkpoints/vpgnet_sam3fp1_best_epoch28.pth`.

Expected SHA256:

```text
150fa0fef23a6e1548a86511754a862cc22ac814e8b05dc6b524dce6ad4b87e1
```

Download the dataset before evaluation:

```bash
bash scripts/download_dataset.sh
```
